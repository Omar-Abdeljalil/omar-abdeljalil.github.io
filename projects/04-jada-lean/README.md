**Applying the Toyota Production System to a Jordanian custom-door manufacturer (est. 1972)**

## Scope

Analyzed the 8-process door production line at Jada Company (Laser Cutting → Bending → Assembly → Compressing → Surface Finishing → Painting → Oven Curing → Accessory Assembly), then designed a targeted future state addressing the three highest-impact waste categories.

## Part I — TPS foundations

Deep dive on the origins and principles of the Toyota Production System, plus comparative analysis of alternative production systems: Ford Production System, Agile Manufacturing, Volvo Production System (VPS), Porsche Production System (PPS), and Boeing Production System (BPS). Grounded in real historical context (Sakichi Toyoda → Kiichiro → Eiji → Ohno) rather than tool-list summaries.

## Part II — Current-state analysis

- **38-step process chart** classifying every activity (operation, transport, inspection, delay, storage)
- **Current-state VSM** across all 8 processes with cycle times, lead times, C/A ratios
- **Takt time** = 144.1 min/door (480 min ÷ 3.33 doors/day)
- **OEE** = **29%** (Availability 93.75% × Performance 78.66% × Quality 39.43%)
- **Total lead time = 613.2 min/door**, of which only **106.2 min is value-added** — 84.7% waste

## Three improvement opportunities identified

| # | Waste type | Root cause | Countermeasure | Impact |
|---|-----------|-----------|----------------|--------|
| 1 | **Overprocessing** — Surface Finishing | No SOP for Ra roughness standard | PDCA cycle: define Ra std, visual SOP, train, quarterly audits | −3 min/door |
| 2 | **Waiting** — Paint→Oven→Accessory | No visual signal for door status | Visual Management: Andon board, Timed Ticket Cards, colour-coded zones | −5 min/door |
| 3 | **Transportation** — Bending→Assembly | Layout misaligned with process sequence | U-cell redesign co-locating Bending and Assembly | −63% travel distance |

## Future-state results

- Lead time: **613 → 561 min/door**
- Activity ratio: **20.55% → 23.3%**
- Reclaimed capacity: **~48 productive hours/month** at 80 doors
- **No headcount increase, negligible capex**

## Tools & methods

- **Process chart** (38 steps, 5 activity classes)
- **VSM** — current + future state
- **OEE calculation** — Availability × Performance × Quality
- **5-Whys** root cause analysis
- **DMAIC** for the transportation waste analysis
- **PDCA** for the overprocessing standardization
- **Visual Management** — Andon, Timed Ticket Cards, floor zones
